# 📱 موقع ومعرض تطبيقات الأندرويد للمطورين (Android Apps Showcase & Store)

منصة ويب عصرية وخفيفة ومجهزة خصيصاً لمطوري تطبيقات الأندرويد لعرض ونشر تطبيقاتهم مع إمكانية التحميل المباشر بصيغة APK أو التوجيه لمتجر Google Play، واستقبال التقييمات والتعليقات المباشرة، مع لوحة تحكم وإحصائيات ذكية للزوار.

---

## ✨ المميزات الرئيسية للموقع

### 1. 🌟 واجهة الزوار (الواجهة الرئيسية):
- **تطبيق ويب تقدمي (PWA)**: زر تثبيت فوري للموقع على شاشة الجوال ليعمل كتطبيق مستقل وسريع بدون متصفح.
- **تواصل مباشر عبر واتساب وفيسبوك**: أزرار مخصصة للتواصل المباشر مع المطور عبر WhatsApp و Facebook.
- **معرض التطبيقات**: عرض بطاقات التطبيقات بشكل أنيق مع الأيقونة، الاسم، الإصدار، الحجم، والتصنيف.
- **تفاصيل التطبيق**: صفحة منبثقة تفاعلية (Modal) تحتوي على معرض لقطات الشاشة (Screenshots)، المميزات، والوصف الكامل.
- **التحميل الفوري وتتبع التنزيلات**: زر تحميل مباشر لملف الـ APK مع عداد حقيقي للتنزيلات، أو زر التوجيه إلى Google Play.
- **نظام التقييم والتعليقات**: يمكن للزوار كتابة الاسم، التقييم بالنجوم (1 إلى 5)، وكتابة تعليق فوري يظهر مع التاريخ.
- **بحث وتصنيف فوري**: فلترة التطبيقات حسب التصنيف (أدوات، إنتاجية، ألعاب، إسلامي...) وشريط بحث فوري.
- **متجاوب 100% مع الجوال**: تصميم سلس ومناسب تماماً لجميع مقاسات الشاشات والهواتف الذكية.
- **الوضع الليلي والنهاري (Dark / Light Mode)**.
- **ملف المطور التعريفي (Hero Section)**: اسمك، لقبك، نبذة عنك، وصورتك الشخصية.

---

### 2. ⚙️ لوحة التحكم الخاصة بالمسؤول (`/admin`):
- **حماية وتسجيل دخول آمن**: الدخول عبر كلمة مرور مشفرة.
- **إحصائيات وتحليلات الزوار**:
  - إجمالي الزيارات، زوار اليوم، الزوار الفريدين، إجمالي التنزيلات، وإجمالي التعليقات.
  - سجل أحدث الزيارات (الوقت، المسار، المتصفح).
- **إدارة التطبيقات (CRUD)**:
  - إضافة تطبيق جديد: رفع الأيقونة، ملف الـ APK، لقطات الشاشة، وتحديد الاسم والتصنيف والمميزات.
  - تعديل وحذف التطبيقات القائمة.
- **إدارة التعليقات والتقييمات**: استعراض كافة التعليقات مع إمكانية حذف التعليقات العشوائية أو غير اللائقة.
- **تخصيص الملف الشخصي**: تعديل اسم المطور، النبذة، البريد، الروابط، وتغيير كلمة مرور لوحة التحكم.

## 🚀 التشغيل السريع على جهازك المحلي

المشروع مبني باستخدام **Bun** (مما يجعله سريعاً وخفيفاً جداً بدون أي تعقيد):

```bash
# تشغيل السيرفر
bun run server.ts
```

- رابط الموقع للزوار: **`http://localhost:3000`**
- رابط لوحة التحكم: **`http://localhost:3000/admin`**
- **كلمة المرور الافتراضية للوحة التحكم:** `admin123` *(يمكنك تغييرها من تبويب الإعدادات)*

## 🌐 طرق الرفع والاستضافة أونلاين (Hosting)

يمكنك رفع الموقع بسهولة على عدة خدمات استضافة مجانية أو مدفوعة:

### 1. الاستضافة عبر Render.com (مجاني وسهل جداً):
1. قم برفع المجلد إلى حسابك في **GitHub**.
2. سجل دخولك على [Render.com](https://render.com) واضغط **New Web Service**.
3. اختر مستودع الـ GitHub الخاص بك.
4. في خيار **Environment** اختر `Docker` (أو استخدم أمر البناء `bun run server.ts`).
5. اضغط **Deploy Web Service** ومبروك موقعك أصبح متاحاً للعامة مع رابط مجاني وشهادة SSL!

### 2. الاستضافة عبر Railway.app:
1. ارفع الكود إلى GitHub ثم افتح [Railway.app](https://railway.app).
2. اضغط **New Project** -> **Deploy from GitHub repo**.
3. سيقوم Railway تلقائياً بقراءة `Dockerfile` وتشغيل الموقع فوراً.

### 3. الاستضافة على سيرفر خاص (VPS / Ubuntu / Debian):
```bash
# تثبيت Bun
curl -fsSL https://bun.sh/install | bash

# تشغيل المشروع عبر PM2 ليبقى يعمل في الخلفية دائماً:
bun install -g pm2
pm2 start server.ts --name "android-store" --interpreter bun
pm2 save
```
